# 숨비 실시간 시연 (본선용)

제안서 4쪽 [그림 3]의 1분 흐름을 노트북 한 대에서 실제로 돌린다. 인터넷 없이 동작한다(음성 합성·음성인식·LLM 모두 로컬).

```
[CSI 입력] → 게이트웨이(gateway.py) ─특징값·경보(HTTP)→ 관제 서버(control.py) ─실시간(SSE)→ 웹 관제 화면
 시뮬레이터     1차 감지 + 음성 확인                      RAG 요약(demo/rag)              브라우저
 또는 ESP32     (스피커로 묻고 마이크로 듣기)
```

| 파일 | 역할 |
|---|---|
| `csi_source.py` | 입력: `SimCSI`(시뮬레이터, 화면에 '시뮬레이션 입력' 표시), `SerialCSI`(ESP32 `csi_recv` 직렬 출력, 보드 오면 사용 — 아직 실기 미검증) |
| `features.py` | 1차 감지: 움직임 지수, 호흡수(신호 대 잡음비), 낙상 의심, 호흡 신호 없음. 시작 10초 보정 |
| `voice.py` | Windows 한국어 음성(Heami)으로 묻고, 마이크 8초 녹음 → Whisper small 받아쓰기 → 정상·도움 요청·무응답 |
| `gateway.py` | 집 안 게이트웨이: 감지 → 관제에 '확인 중' → 음성 확인 → 결과 전송. 원본 CSI는 보내지 않음 |
| `control.py` | 관제 서버(FastAPI): 경보마다 RAG 요약, 웹 화면으로 실시간 전달, 시연 버튼 처리 |
| `static/index.html` | 관제 화면(외부 라이브러리 없음). `?snapshot=1`은 실시간 연결 없이 현재 상태를 한 번 그림(캡처·백업용) |
| `start_demo.bat` | 한 번에 실행 |

## 119 자동 신고(시연)
- 낙상·호흡 이상 뒤 음성 확인 결과가 **무응답** 또는 **도움 요청**이면 15초 카운트다운 후 119 자동 신고(현행 응급안전 4차 장비의 '15초 취소 안내 뒤 자동 호출'과 같은 방식). 관제 화면·요원 앱에서 [취소(직접 확인)]·[즉시 신고]. 화재는 즉시 신고.
- 실제 119로 발신하지 않는다(화면 '시연' 표시). 출동 여부는 119 상황실이 정한다.
- 시험(2026-11-12): 감지 +15초 무응답 → 카운트다운 → +30초 자동 신고 완료 / 카운트다운 중 취소 확인.

## 클라우드 방식 (Render + 요원 앱 푸시)
```
[노트북] gateway.py ──5G 핫스팟·인터넷──▶ [Render] control.py --rag worker ──Expo 푸시──▶ [요원 폰 앱 진동]
[노트북] rag_worker.py ◀── 요약 요청 / 요약 결과 ──▶   (어르신 기록은 노트북에만 = 망 내 AI 역할)
```
1. `demo/live` 폴더를 새 GitHub 저장소로 올린다(`render.yaml`이 맨 위에 오도록). 어르신 기록(demo/rag/data)은 올리지 않는다.
2. Render 대시보드 → New → Blueprint → 저장소 선택 → 배포. Environment에서 생성된 `SUMBI_KEY` 값을 복사.
3. 노트북: `start_cloud.bat https://<서비스>.onrender.com <SUMBI_KEY>` → 작업기·게이트웨이 실행, 관제 화면이 열린다.
4. 요원 폰 앱(demo/app/sumbi-app)에 Render 주소와 키 입력.
5. 무료 요금제는 15분 동안 요청이 없으면 잠들고 깨는 데 약 1분 → 시연 2분 전에 `start_cloud.bat` 실행(게이트웨이가 1초마다 보내므로 시연 중에는 잠들지 않음).
- 시험(2026-11-12, 이 PC에서 같은 구성): 키 없는 쓰기 401, 작업기 요약 약 7초, Expo 푸시 서버 응답 약 0.23초(가짜 토큰으로 경로만 확인).

## 시험 결과 (2026-11-12, RTX 3070, 시뮬레이션 입력)
- 낙상 → 감지 약 7초, 무응답 확인 +15초(음성 생략 시험), AI 근거 요약 완료까지 낙상 후 약 29초(목표 60초)
- 화재: 즉시 P1, 요약 약 6.5초
- 관제로 보낸 데이터: 약 4분에 15KB, 원본 CSI 전송 0B
- 음성인식(합성 음성 파일로 시험): "괜찮아요" → 정상, "아파요, 못 일어나겠어요" → 도움 요청, 알아듣기 어려운 말 → 도움 요청(안전 쪽), 무음 → 무응답. 받아쓰기 1~2초

## 한계·정직하게 밝힐 점
- 지금 입력은 시뮬레이터다. 실측은 ESP32(표준 이전 CSI) 연결 후 `features.py` 임곗값을 현장 보정으로 맞춰야 한다. 802.11bf 칩이 아니다.
- 5G SA 슬라이스·AI-RAN은 재현하지 않는다. 관제 서버를 다른 PC에 두고 게이트웨이를 휴대폰 5G 핫스팟으로 붙이면 상용망 전송 지연(화면 상단 ms)만 보여 줄 수 있다.
- 대상자·지침은 가상 자료다(demo/rag/data).
- 현장 실패 대비: 리허설 때 화면 녹화 영상을 만들어 둔다.
